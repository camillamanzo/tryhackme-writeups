# Logs Fundamentals

## 📋 Overview

Logs are records of events generated by systems, applications and devices. In security, they are essential for:

| Use Case | Description |
|----------|-------------|
| **Security Event Monitoring** | Detect anomalous behaviour in real time |
| **Incident Investigation & Forensics** | Detailed record of what happened during an incident |
| **Troubleshooting** | Diagnose and fix system and application issues |
| **Performance Monitoring** | Insight into application and system performance |
| **Auditing & Compliance** | Establish an audit trail of activities for regulatory requirements |

---

## 🗂️ Log Types

| Type | Description | Primary Use |
|------|-------------|-------------|
| **System Logs** | OS activities — services, drivers, hardware events | Troubleshoot OS issues |
| **Security Logs** | Security-related activities — auth, account changes, policy changes | Investigate and detect incidents |
| **Application Logs** | Events specific to an application — errors, crashes, user actions | App-level troubleshooting |
| **Audit Logs** | System changes and user events | Compliance requirements |
| **Network Logs** | Network traffic info — connections, transfers, protocol details | Network troubleshooting and IR |
| **Access Logs** | Info about access to different resources | Access control and investigation |

---

## 🪟 Windows Event Logs

### Log Categories

| Category | Contents |
|----------|----------|
| **Application** | Events from applications running on the OS — errors, warnings, compatibility issues |
| **System** | OS operations — drivers, hardware, startup, shutdown, service events |
| **Security** | Security-related activities — user authentication, account changes, policy modifications |

### Event Viewer

Windows built-in utility to view, search and filter event logs.

| Field | Description |
|-------|-------------|
| **Description** | Detailed info about the activity |
| **Log Name** | The log file the event belongs to |
| **Logged** | Timestamp of the activity |
| **Event ID** | Unique identifier for a specific type of activity |

**To filter by Event ID:**
```
Event Viewer → select log category → Filter Current Log → enter Event ID
Double-click any log entry to view full details
```

### Common Event IDs (Security Log)

| Event ID | Activity |
|----------|----------|
| `4624` | Successful logon |
| `4625` | Failed logon |
| `4720` | User account created |
| `4726` | User account deleted |
| `4732` | User added to a privileged group |
| `4688` | New process created |

## 🌐 Web Server Access Logs

Log files stored on the web server — contain details of every HTTP request made to the site.

**Apache log location:** `/var/log/apache2/access.log`

### Log Entry Fields

| Field | Description | Example |
|-------|-------------|---------|
| **IP Address** | IP of the user who made the request | `192.168.1.1` |
| **Timestamp** | When the request was made | `[12/Apr/2026:10:32:01 +0000]` |
| **Request** | HTTP method and URL requested | `GET /index.html HTTP/1.1` |
| **Status Code** | Server's response code | `200`, `404`, `500` |
| **User-Agent** | Browser and OS of the requester | `Mozilla/5.0 (Windows NT 10.0)` |

## ⌨️ Command Line — Log Analysis

### Basic Commands

| Command | Description | Example |
|---------|-------------|---------|
| `cat` | Display log contents | `cat access.log` |
| `cat` (combine) | Merge multiple log files | `cat access1.log access2.log > combined.log` |
| `grep` | Search for a specific string | `grep "192.168.1.1" access.log` |
| `less` | View log one page at a time | `less access.log` |

### `less` Navigation

| Key | Action |
|-----|--------|
| `Space` | Next page |
| `b` | Previous page |
| `/word` | Search for a specific word |
| `n` | Jump to next occurrence of search |
| `N` | Jump to previous occurrence of search |
| `q` | Quit |

### Useful One-Liners

```bash
# View log contents
cat access.log

# Combine multiple logs into one file
cat access1.log access2.log > combined_access.log

# Filter for a specific IP address
grep "192.168.1.1" access.log

# Filter for a specific status code (e.g. all 404 errors)
grep " 404 " access.log

# Count how many times an IP appears
grep -c "192.168.1.1" access.log

# View log interactively, one page at a time
less access.log

# Show only the last 50 lines (useful for live monitoring)
tail -50 access.log

# Follow log in real time (like a live feed)
tail -f access.log
```
